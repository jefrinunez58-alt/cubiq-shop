## 4. Lista de verificación — fotografías propias (CUBIQ)

Usar esta lista **antes** de marcar una fotografía propia como `Fotografía propia recibida` / `En revisión`. **No integra imágenes.**

- [ ] Se confirmó la **variante exacta** del producto físico (marca, modelo, versión, acabado, SKU si aplica) y coincide con la ficha (§3).
- [ ] La foto corresponde **1:1** al producto (no es otro modelo, otra variante, otro tamaño ni un producto similar).
- [ ] La foto es **real** (no ilustración, no render, no imagen generada, no SVG usado como foto).
- [ ] Formato adecuado para web (p. ej., JPG/PNG/WebP según decisión técnica futura) y archivo **no corrupto**.
- [ ] Resolución suficiente (objetivo recomendado **≥ 1000 × 1000 px**; registrar resolución real).
- [ ] Encuadre limpio: producto centrado, fondo uniforme/neutro (recomendado), sin marcas de agua de terceros no autorizadas.
- [ ] Iluminación uniforme, enfoque nítido, colores razonablemente fieles (sin filtros que alteren la identificación).
- [ ] Se capturaron ángulos mínimos recomendados (según corresponda): frontal, 3/4, detalle distintivo (logo/mecanismo/variante si visible), empaque/etiqueta con variante/SKU (si está disponible y es legible) — **solo si ayuda a verificar correspondencia**.
- [ ] Nombre de archivo descriptivo y consistente con la estructura de carpetas (§6).
- [ ] Registro completado: fecha, responsable interno, variante/SKU, resolución, observaciones.
- [ ] Criterios de aceptación/rechazo (§5) evaluados y documentados.

## 5. Criterios para aceptar o rechazar cada imagen

**Resultado:** `Aceptar para integración` (solo como estado de preparación, **no integra**) o `Rechazar / Pendiente de corrección`. Registrar motivo.

| Criterio | Aceptar (ejemplos) | Rechazar / mantener pendiente (ejemplos) |
|---|---|---|
| **Correspondencia exacta (1:1)** | Coincide marca, modelo y **variante** confirmada; tipo/categoría correctos (2×2/3×3/4×4/Pyraminx/Megaminx). | Variante distinta, modelo parecido, generación/revisión diferente no confirmada, duda razonable. |
| **Calidad visual** | Enfoque nítido, iluminación uniforme, producto identificable, sin artefactos graves. | Borrosa, oscura/sobreexpuesta, recortada mal, ruido/compresión excesiva, fondo distractor que impida identificar. |
| **Resolución** | **≥ 1000 × 1000 px** (objetivo) o resolución suficiente acordada; registrar valor real. | Muy baja para uso de catálogo/detalle; no se puede verificar nitidez. |
| **Formato** | Formato web válido (JPG/PNG/WebP) no corrupto; metadatos/colores razonables. | Archivo dañado, formato no apto sin conversión controlada, o conversión que degrade evidencia. |
| **Procedencia** | (a) **Fotografía propia** con registro interno; o (b) **comercial/fabricante/distribuidor** con **autorización/licencia compatible verificable** y evidencia archivada. | Origen desconocido, descarga sin permiso, “publicada en web” sin licencia/autorización, términos no compatibles/no verificables. |
| **Evidencia** | Ficha completa + archivo en carpeta prevista + evidencia de autorización (si aplica). | Falta evidencia, falta variante/SKU confirmado, falta registro de términos. |

**Regla crítica:** si falta correspondencia 1:1 o falta autorización/licencia verificable (cuando la foto es de tercero), la imagen **no** pasa a `Listo para integración`.

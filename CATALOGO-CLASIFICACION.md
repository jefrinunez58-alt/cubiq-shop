# CUBIQ — Inventario y clasificación propuesta (catálogo mixto: real + genérico)
**Fase:** solo auditoría/propuesta. **No se modificó código, diseño, colores, tarjetas, navegación ni funcionalidades. No se eliminaron productos ni archivos.**  
**Fuente auditada:** `src/data/products.ts` (50 productos activos) + `IMAGE-AUDIT.md` (estado de imágenes).  
**Criterios aplicados:** no se inventan marcas/modelos/especificaciones; no se asignan fotos entre productos; **los SVG actuales no son fotografías reales**; no se descargan/reutilizan fotos sin verificar condiciones de uso; se conservan productos genéricos cuando no hay información comercial verificable.

## Resumen
- **Total:** 50 productos (8 categorías, todas ≥6). Accesorios: 8.
- **Clasificación actual en datos:** 50/50 son entradas de **demostración** (`CUBIQ Demo/Studio/Pro/Variants/Control/Care/Gear (demo)`), sin marca/modelo comercial verificado.
- **Imágenes:** 50/50 usan **SVG (dibujo/placeholder)** — **no fotografía real**. 28 JPG heredados: **descartados para asignación** (sin correspondencia/licencia confirmada); originales conservados.
- **Fotografías reales adecuadas verificadas y autorizadas para asignar:** **0**. Investigación previa: fabricantes/distribuidores sin licencia/autorización expresa clara localizada; Wikimedia Commons tiene algunas fotos reales CC de cubos 3×3 **genéricos** (p. ej. CC BY 2.0 / CC BY-SA) — **no corresponden 1:1 a modelos de marca específicos** y requieren atribución/cumplimiento + decisión del usuario; **no aptas** para asignar por semejanza a SKUs/modelos concretos.

## Propuesta para tienda mixta
- **Genérico (conservar):** mantener como producto genérico/demo hasta contar con marca, modelo, especificaciones, foto real 1:1 y licencia/autorización verificadas. Útil para completar catálogo sin inventar datos.
- **Real (convertir solo con verificación):** convertir una entrada a “real” **únicamente** cuando se confirme: marca + modelo comercial exacto, categoría/tipo correcto, especificaciones verificables, **fotografía real adecuada** del producto específico (1:1) y **condiciones de uso/autorización/licencia** verificadas. Requiere mapeo explícito y revisión antes de integrar.
- **No hacer:** no sustituir SVG por “foto real”; no usar JPG heredados sin confirmación humana de contenido/correspondencia/licencia; no mapear fotos genéricas a modelos de marca; no eliminar entradas.
